# Заглушки текстур

В коде подготовлены пути для будущих JPG/BMP-текстур моделей игры:

- `player_tank.jpg` / `player_tank.bmp` — танк игрока
- `enemy_tank.jpg` / `enemy_tank.bmp` — танк врага
- `brick_wall.jpg` — кирпичная стена
- `steel_wall.bmp` — стальная стена
- `bullet.jpg` — пуля

Сами бинарные изображения не добавлены, чтобы pull request оставался текстовым.
