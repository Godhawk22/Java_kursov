# Java_kursov

Мини-игра на Java (Swing), похожая на классическую **Tanky 1990 / Battle City**.

## Как запустить

```bash
javac src/Tanky1990Game.java
java -cp src Tanky1990Game
```

## Управление

- `W A S D` или стрелки — движение танка
- `Space` — выстрел
- `R` — перезапуск после Game Over

## Механики

- Разрушаемые кирпичные блоки
- Неразрушаемые стальные стены
- Вражеские танки с простым AI
- Счет и жизни
